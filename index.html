Graduation project: AI-enhanced IDS/IPS

Arab Open University, 2025. Presented at the AOU Graduation Expo 2025 to faculty and industry professionals.

I built a system that detects network attacks and responds to them. A Random Forest classifier, trained on KDD Cup 99 and CIC-IDS2018 DoS data, separates normal traffic from SYN floods and port scans. It reached over 99% accuracy on benchmark test data.

  1. CaptureLive packets collected with Scapy
  2. ClassifyRandom Forest labels normal, SYN-flood and port-scan traffic
  3. MonitorPrometheus and Grafana dashboard for live visibility
  4. RespondAutomated IP blocking through iptables

The accuracy figure comes from benchmark datasets, not a production network. I documented the design, testing and limitations in a full project report, and I’m glad to walk through them in an interview.

CMYK color collector and swatch sheet generator

Click colors with the Eyedropper, then build a production-ready CMYK swatch document in one step.

  • Plain scripts can’t listen to tool clicks, so I used Photoshop’s notifier system. A handler on the Set event filters for foreground-color changes and stores each color as CMYK values in session memory. No files are created and the source document is never modified.
  • The generator makes one 3 × 3 cm square per color, each on its own layer, at 254 ppi so 1 cm is exactly 100 px. Colors are grouped in sets of 15, and the canvas size is calculated from the color count.
  • It warns before reaching Photoshop’s canvas and layer limits, and the README lists known limitations and troubleshooting steps.

Smart Object fill

Fills many shape layers with the same design in one run.

  • Duplicates one source Smart Object into every selected shape layer, centers each copy over its shape and applies a clipping mask.
  • Keeps the original size and scale, leaves the source unchanged, and names each copy after its target layer.

Date and job-code generators

Two scripts, wired to Photoshop Actions so they run in one click.

  • One creates an editable text layer with today’s date as YYYY-MM-DD.
  • The other fills the selected text layer with the next job code in the sequence and saves the last number to a counter file, so numbering continues between sessions.
